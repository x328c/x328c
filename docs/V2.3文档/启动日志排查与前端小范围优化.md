## 本次小范围优化

### 图片检查

`upload.ts` 使用 `getFileSystemManager().getFileInfo` 替代旧的 `Taro.getFileInfo`，正确包装回调而非等待 void 返回值。文件读取失败或大小无效时停止上传。

保持不变：临时路径、MIME 判断与降级、5MB 上限、所有上传分类、获取 COS 签名的地址及参数、COS 上传参数、上传完成回调与返回 URL；未上传任何真实图片做测试。

### 启动/前台未读数

新增 `notification-refresh.ts`，仅用于 App 前台刷新：

- 相同会话和通知状态的并发刷新共享一个进行中的请求；不持久缓存，每次后续进入前台仍可更新。
- 旧请求不能覆盖已读操作、新通知状态或切换后的账号。
- 保留普通 Token 自动更新后的有效结果。
- 请求失败不新增自动重试、不制造启动弹窗；以后刷新仍可重试。
- 不更改通知列表、已读接口、请求地址或参数，不修改后端。
