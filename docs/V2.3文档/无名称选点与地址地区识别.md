# 无名称选点与地址地区识别

日期：2026-09-03。本次修订以用户最新要求为准，覆盖此前“地区全部手动确认”的交互要求。

## 无名称点位

- 微信原生地图返回有效经纬度时，允许 `name` 为空；优先以地址作为名称，名称和地址均为空则使用“地图选点”。不修改真实坐标。
- 截图中 `chooseLocation:fail` 是原生 API 未返回结果，不是业务端仅因名称为空拒绝。此时不能恢复微信没有返回的地图中心坐标。
- 对普通原生失败，提示“改用地图自由选点？”。用户同意后进入新增地图页，重新拖动地图，将目标位置移到十字准星，点击“使用地图中心点”。名称选填。
- 自由选点保存时读取实际 `MapContext.getCenterLocation()`；不使用附近 POI、上一点坐标或页面默认坐标冒充当前选择结果。
- 自由选点不做地址检索和逆解析，地址为空，保存后需确认所属地州市。可点击“定位到我”申请使用当前位置，不主动获取位置。
- 取消、隐私协议缺失、权限拒绝不触发自由选点替代，不绕过权限。地图组件错误时禁用确认，防重复提交；返回上一页通过事件通道取消未完成选择。

## 地址自动填写

- 仅使用微信返回的 `address`，不依赖微信端未定义的 `cityName`，不使用地点名称推测地区。
- 规范空白、全半角及地址开头的“中国”“新疆维吾尔自治区”等前缀。
- 优先匹配现有新疆目录的完整地州市名称；如只有目录内唯一的区县/县级市前缀，则映射到其所属地州市。
- 示例：`新疆维吾尔自治区塔城地区乌苏市Y096`、`乌苏市Y096` → 塔城地区 / 乌苏市；`新疆维吾尔自治区克拉玛依市独山子区柳南路` → 克拉玛依市 / 独山子区。
- 短简称、非新疆地区、路名/店名中包含城市、冲突的行政区或重名区县不自动填写；保留地区确认弹层。
- 自动填写后沿用点位旁“修改”入口，允许人工纠正。重新选点不继承旧点地区，也不把首页地区自动写入。
- 文本识别是填写辅助，不能证明经纬度位于某个行政边界内；后端继续校验地区代码及父子关系。用户仍应复核跨区域点位。
- 不新增腾讯地图 Key，不调用逆地址服务，不改数据库结构，不回填已有业务数据。

## 验证

自动化覆盖：空名称/地址、无效坐标、跨城市地址、县级市到地州映射、地址冲突、取消和权限失败、自由选点事件通道、保存实际地图中心、防重复确认，以及登录请求和路线列表回归。原生地图表现仍需真机复测。

## 真机复测

1. 结束旧调试并重新编译扫码，保持手机与电脑在同一局域网。
2. 有完整地址的地点应直接填入所属地州市；例如乌苏市不应再默认归为乌鲁木齐。
3. 原生选择空旷无名称点若返回失败，确认“自由选点”，重新将该位置拖到地图中心后保存，确认实际地区。
4. 分别测试同行集合点、途经点、终点及路线起点、途经点、终点；保存后检查详情地图坐标和城市筛选。
