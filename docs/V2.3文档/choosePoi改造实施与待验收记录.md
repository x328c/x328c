# choosePoi 城市归属改造实施与待验收记录

记录日期：2026-09-03。状态：实施中，不能视为已发布或全部验收通过。

## 已实现并进行自动化检查

- 同行与骑友路线统一使用 `utils/poi-region.ts`；只接受具体 POI（type=2）。
- 城市名称映射新疆受控目录；空值或未知名称进入人工确认。全局浏览城市仅作为人工选择器初始候选，不自动写入点位。
- 每个点位允许修改城市及可选区县；提交时清除展示专用名称字段，避免严格 DTO 校验报错。
- 修复“修改地区”直达入口的目录加载未捕获异常：失败提示重试且保留原点位；空目录不缓存，重试重新请求；同一时刻的目录请求复用。人工候选城市不写入原点位，须点击确认。
- 城市匹配改为目录全称优先、受控别名精确匹配；不再删除任意行政区后缀，防止错误名称被当成合法城市；歧义别名转人工确认。
- 接入地区选点成功/失败、城市映射成功/失败、人工确认、保存地区校验拒绝六类事件；前后端过滤敏感字段，地区事件不保存用户ID，上报超时3秒且跳过登录态恢复。统计口径及未完成事项见[地区识别监控与验收口径](./地区识别监控与验收口径.md)。
- 后端三个保存入口删除 enrich/逆地址解析调用；RegionService 验证地市、区县父子关系、省代码及粗略经纬度范围。粗略范围不等于真实行政区边界校验。
- 骑友路线增加 end_point 请求和详情字段，复用 user_route_points 保存终点地区；编辑事务重建覆盖，支持清空旧起点区县。
- 关联路线未自定义时以服务端保存点位为准；显式 route_customized 时验证并保存用户自定义点位，快照不沿用旧道路折线。再次发起保留历史点位，不自动覆盖为最新路线。
- 后台地图点位增加逐点城市/区县选择，起点驱动主归属字段。
- 官方路线补齐主地区一致性：禁止只改主城市/区县而不改起点；跨城起点不继承旧顶层区县；发布前逐点校验地区并在事务内再次检查当前记录、重建覆盖表。旧草稿缺城市或主地区冲突须先编辑修复，不能直接发布。
- 旧 TENCENT_MAP_KEY / TENCENT_MAP_SECRET 从本地 backend/.env、模板和 Compose 中移除；没有复制其密钥值。独立道路规划仅读取可选 TENCENT_MAP_ROUTE_KEY / TENCENT_MAP_ROUTE_SECRET；后台 Web JS 展示配置不参与地区识别。
- 修复关键词 OR 覆盖城市 OR、官方路线游标 AND 覆盖途经条件的问题。
- 官方路线、骑友公开路线按“本地起点→仅途经本地”分组读取后分页；游标携带分组，切换组时清空上一组游标。骑友公开路线使用时间/ID复合游标，兼容读取旧数字游标。
- 有城市筛选或定位的同行使用参数化SQL：按索引获取城市候选ID，在数据库内完成地区优先级、距离、筛选与分页，再读取当页关联详情；计数与分页使用事务保持一致。不再向应用层加载全部同行及关联数据。无城市且无定位仍使用普通分页。
- 路线首页删除“官方/骑友各取前50条后结束”的截断逻辑，支持上拉/点击继续加载；跨来源按本地起点优先，再仅途经本地，同组内保留官方优先及各接口内部排序。筛选变更丢弃旧游标，过期请求不覆盖新列表，追加失败保留列表并可重试。
- 官方与骑友路线的仅途经查询显式兼容主城市/区县为 NULL 的旧数据，避免 SQL 三值逻辑误排除已有覆盖匹配的记录。
- 历史回填脚本保留已存点位地区及已有折线，不覆盖为无地区终点或直线。
- 地区回填升级为逐条计划/校验：任一点位缺城市、代码非法、快照不一致则整条拦截；已有点位保留 ID，只更新必要地区字段，不再删除重建。按100条ID批量扫描、逐条处理，输出脱敏报告与原子检查点。
- 续跑校验数据库哈希、目录版本、格式和模式；指纹一致的已核验记录跳过，待处理/失败/变更记录重新检查。apply 实现事务内重读、指纹比较及写后无差异复核，但未对真实数据库执行 apply。
