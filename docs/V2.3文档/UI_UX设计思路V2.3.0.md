# 摩搭子助手 V2.3.0 UI/UX 设计思路

## 1. 设计原则

1. 地图用于确认，不让用户理解坐标、城市码或 JSON。
2. 先展示核心信息，再提供导航、分享和再次发起等动作。
3. 关键操作前补资料，普通浏览不强制，补全后返回原任务。
4. 所有外链、定位和路线降级状态必须可理解，不用静默失败。
5. 沿用 V2.2 白底卡片、浅灰背景和活力橙主操作色；危险动作使用红色。

## 2. 全局城市/地区选择

### 2.1 入口

- 同行首页和路线首页左上角统一显示“当前地区 + 下拉箭头”。
- 删除路线页“输入城市码”控件。
- 首次进入默认乌鲁木齐，同时提供“使用当前位置”和“手动选择”。

### 2.2 选择页/弹层

结构：

1. 当前选择；
2. 定位推荐（有授权时）；
3. “全疆”；
4. 地州/市列表；
5. 选中城市后的区县列表；
6. 最近选择。

切换后关闭弹层并刷新当前页面，返回顶部。空状态显示“该地区暂时没有同行/路线”，同时提供“发起同行”“录入路线”和“切换地区”。

## 3. 用户路线录入

### 3.1 页面顺序

1. 标题与说明；
2. 地图路线编辑器；
3. 里程、时长和难度；
4. 第三方路线链接；
5. 图片；
6. 可见性；
7. 保存。

### 3.2 地图编辑器

- 起点、途经点、终点以编号卡片展示；点击卡片进入地图选点。
- 途经点支持“添加途经点”，上限 20；支持拖拽，微信端拖拽不稳定时提供上移/下移。
- 地图用橙色实线显示已规划轨迹，起点绿色、途经点橙色、终点红色。
- 点位变更后显示“正在生成路线轮廓”；失败显示“暂时无法规划道路，仍可保存点位”，并提供重试。
- 折线降级为点间虚线时，在地图下明确标注“不代表实际可通行道路”。

### 3.3 第三方链接

字段名“第三方路线链接（选填）”，附“支持的平台”说明。失焦或保存时校验：成功显示平台标签；不支持则阻止公开发布但允许用户删除链接后继续。

## 4. 路线详情

- 地图区展示折线、编号点位和“展开地图”。
- 地图下提供操作条：`导航到起点`、存在终点时 `导航到终点`、验证通过时 `打开完整路线`。
- 页面右上角微信原生分享和正文内“分享路线”按钮共用同一分享配置。
- 私密路线显示“仅自己可见”，隐藏分享入口。
- 第三方跳转失败时弹窗提供“复制链接”，不反复跳转。

## 5. 管理后台官方路线编辑

将“抽稀折线 JSON”和手工经纬度输入替换为地图编辑区：

- 左侧/上部地图，右侧/下部点位列表；宽屏双栏、窄屏上下布局。
- 地址搜索后在地图确认；新增点默认途经点。
- 只有一个起点和一个终点；发布校验在字段旁就地提示。
- 顶部显示城市、区县、折线状态、里程和时长。
- “重新规划”是次按钮，“保存草稿”与“发布”分开。
- 高级 JSON 仅在排障折叠面板中只读展示。

### 5.1 用户发布路线管理

在“路线管理”页新增独立卡片“用户发布路线管理”，不与官方路线的新增/编辑表单混用：

- 顶部筛选：标题/起终点/发布者关键词、状态、可见性、城市；支持重置。
- 表格展示：封面、标题、发布者、起终点、可见性、状态、收藏/评论、更新时间及操作。
- 状态文案明确区分“正常”“管理员下架”“用户已删除”，避免运营误判。
- “详情”弹窗展示图片、说明、完整有序点位、地区覆盖、关联同行数和下架原因；默认不展示用户手机号或微信号。
- “下架”使用危险色二次确认并强制填写 2～500 字原因；成功后刷新列表。
- “恢复”仅对管理员下架记录和超级管理员显示；用户已删除记录不显示恢复按钮。
- 不提供“编辑用户路线”操作，内容纠错通过下架理由与用户沟通完成。

## 6. 发起同行

### 6.1 页面结构

1. 基本信息；
2. 关联路线；
3. 时间地点；
4. 人数与骑行要求；
5. 说明与协议；
6. 发布。

关联路线后显示“已从路线导入 X 个点位”。集合点仍单独显示，可修改；路线起点、途经点、终点在“行程点位”卡片中按顺序展示。

如果用户已手工修改点位后更换路线，弹窗提示“更换路线将覆盖当前途经点和终点，集合点可继续保留”，默认按钮为取消。

## 7. 同行详情与分享

- 时间地点卡增加终点和途经点摘要；超过 3 个途经点时显示“另有 X 个途经点”。
- 地图可展开查看完整点位快照。
- 分享按钮文案“分享给摩友”，分享标题含活动名称、日期时间和人数，不显示微信号。
- 已取消、已结束、已满员必须在分享进入后的首屏清晰显示。

分享示例：

> 周末南山休闲骑｜9月6日 10:00｜3/8人

## 8. 我的同行与再次发起

保留“我发起的/我报名的”，增加“进行中/历史”二级筛选。历史卡片底部显示 `查看详情` 和 `再次发起`。

点击“再次发起”进入创建页，顶部显示“基于历史同行创建”；已复制字段使用浅橙提示，出发时间显示必填错误直到重新选择。发布前预览摘要，避免误发。

## 9. 资料完善

### 9.1 拦截页

不使用简单 Toast。显示半屏弹层或资料页顶部说明：

> 为便于同行成员识别和联系，请先完善以下资料。微信号由你主动填写，小程序无法自动读取或认证。

字段显示完成状态：头像、用户名称、车型、微信号。保存按钮为“保存并继续报名/发起/发布”。不提供假性“稍后再说”后继续关键操作；可返回取消。

### 9.2 错误状态

- 微信号重复：提示“该微信号已被其他账号填写，请核对或联系客服”，不透露用户身份。
- 图片上传失败：保留其他已填内容，支持重试。
- 保存成功但原操作失败：返回原页面并提示重新点击，不自动重复多次。

## 10. 加载、空状态和无障碍

- 地图与正文分区加载，地图失败不遮挡文字点位。
- 操作按钮必须有文字，不只使用图标；编号点位不只依靠颜色区分。
- 分享、导航、外链、重新规划均防重复点击。
- 城市选择、地图编辑和资料页支持系统字体放大；重要按钮触控高度不少于 44px。
