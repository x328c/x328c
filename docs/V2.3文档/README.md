## 决策摘要

1. 地图上的“路线轮廓”必须来源于道路规划结果或已保存轨迹；点位间直线只作为降级预览，不称为道路导航路线。
2. 小程序首期提供“导航到起点/集合点/终点”；完整多途经点导航优先打开经白名单校验的第三方路线链接，避免虚假承诺。
3. 同行和路线在集合点/起点或任一途经点命中所选地区时进入结果；集合点/起点命中优先排序，纯途经内容必须标注“途经本地”。
4. “途经本地”不代表可从途经点加入同行；详情仍明确展示实际集合点，避免用户误认为活动从本地出发。
5. 不在登录后立即拦截用户浏览；发起同行、报名同行、公开发布路线前必须完成用户名称、头像、车型和微信号四项资料。
6. 微信号为用户手工填写，无法由微信自动验证；本版执行格式与未删除用户范围内唯一性校验，并明确提示不要填写手机号等敏感内容。
7. 管理后台可查询、查看、下架和恢复用户路线，但不得直接改写用户发布内容；用户自行删除与管理员下架必须区分，所有治理操作写入审计日志。

## 明确不做

- 不自动获取微信号或手机号。
- 不开发关注、粉丝、动态流、用户历史次数及信用分。
- 不在小程序内自研逐向导航或后台持续定位。
- 不保证任意第三方网址都可在微信内打开；仅支持配置的 HTTPS 白名单平台。
- 不把“途经本地”误写成“本地出发”，也不承诺可从途经点中途加入。
