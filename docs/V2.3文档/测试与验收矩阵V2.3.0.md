## 2. 边界与异常

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| B-01 | 20个途经点 | 可保存；第21个前后端均拒绝 |
| B-02 | 无终点路线 | 可保存私密路线；只显示导航到起点 |
| B-03 | 折线超过500点 | 服务端抽稀且保留首尾点 |
| B-04 | 相同连续点位 | 拒绝或去重并提示，不产生零长度规划段 |
| B-05 | 地区逆编码失败 | 记录待回填，不猜测城市，不混入其他城市 |
| B-06 | 地图无配额 | 页面文字和点位列表可用，监控告警 |
| B-07 | 分享资源已删除 | 显示已删除/不可用状态，不白屏、不跳错详情 |
| B-08 | 分享同行已取消/结束 | 首屏明确状态，禁止报名 |
| B-09 | 外链重定向到非白名单 | 拒绝打开并允许复制受控原链接或删除 |
| B-10 | 再次发起关联路线已私密/下线 | 仅复制快照，不建立无权关联 |
| B-11 | 旧用户路线 | 无新点位表数据时 | 兼容读取旧起点/waypoints/终点并可迁移 |
| B-12 | 旧同行 | 无RidePoint/快照 | 详情继续显示集合点和目的地文本 |
| B-13 | 重复下架/恢复 | 并发或重复提交同一治理操作 | 仅一次状态变更成功，不产生相互矛盾的审计结果 |

## 3. 数据迁移验收

- 用户路线转换前后：路线数一致；每条起点存在；途经点顺序一致；有终点者终点一致。
- 官方/用户地区覆盖表无重复键；主城市与起点逆编码结果一致。
- 微信号唯一索引创建前重复报告为 0 或均有处置记录。
- 回填脚本重复执行不增加重复点位或地区行。
- 迁移失败清单包含资源 ID、原因和重试状态；不得只打印日志后丢失。
- 历史用户路线新增治理字段均为空；历史 `status=2` 不得被错误标记为管理员下架或允许恢复。

## 4. 兼容与真机

- iOS、Android 各至少一台；当前生产基础库和审核建议基础库各验证一次。
- 微信会话、群聊、朋友圈能力范围内验证分享入口；从冷启动和已登录状态分别打开分享路径。
- 验证 GPS 开/关、拒绝/允许定位、弱网、地图加载失败、从后台恢复。
- 验证小程序分包直达官方路线详情，不出现包未加载或分享超时。
- 后台验证 Chrome 当前稳定版，地图编辑器在 1366px 和 1920px 宽度可用。

## 5. 性能与安全

- 同行/路线列表 TP99 ≤ 300ms，详情 TP99 ≤ 200ms；polyline 不进入列表响应。
- 道路规划 5秒超时；同坐标请求命中缓存；配额耗尽有告警。
- 地区组合索引执行计划不全表扫描主要业务表。
- 对第三方 URL 测试 localhost、私网 IP、DNS 重绑定、超长链接、重定向循环和非 HTTPS。
- 分享标题和路径不得包含微信号、手机号、token 或完整精确地址中的敏感备注。
- 资料完整度必须由服务端复核，直接调用 API 不能绕过。
- 用户路线治理接口验证普通管理员/超级管理员权限边界；下架与恢复操作日志覆盖率为 100%。

## 6. 发布通过标准

1. P0 用例 100% 通过；P1 通过率不低于 95%。
2. 无阻断登录、发起、报名、分享、城市切换、路线保存和后台用户路线治理的缺陷。
3. 迁移演练、备份恢复、feature flag 回退均有证据。
4. 地图服务密钥、域名、配额、告警和隐私说明完成生产配置。
5. 体验版连续运行 24 小时无新增 P0/P1，方可提交审核并安排宣传。
