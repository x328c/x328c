# S5 部署与监控清单

## 发布前

- [ ] 确认 V1 登录、约骑发布/报名、通知成功率和错误率最近 14 天基线。
- [ ] 备份 MySQL，使用隔离副本执行全部增量迁移；确认 `migrate status` 无待执行迁移和漂移。
- [ ] 只在灰度配置中开启 `route.enabled`、`regulation.enabled`；论坛先保持 `forum.enabled=false`、`forum.write_enabled=false`。
- [ ] 内容安全服务文字/图片资质、密钥、超时和人工队列负责人已确认；不把异常当放行条件。
- [ ] Redis 主从、锁 TTL、Key 前缀 `v2:`、命中率和错误告警已验证。
- [ ] OpenAPI、埋点字典、运营 SOP、回滚手册和已知限制已评审。
- [ ] 后端 lint/build/unit/integration/E2E、小程序 typecheck/4/5 Tab build、后台 lint/build 全部通过。

## 灰度期间看板与告警

- API QPS、4xx/5xx 错误率、P95/P99、request ID；列表/详情 P95 目标 ≤300ms、P99 ≤800ms。
- MySQL 慢查询、锁等待、连接池、深分页请求；Redis 错误、延迟、Key TTL 和失效失败。
- 审核通过/驳回/超时率、PENDING 积压、最大重试数、人工队列年龄。
- 计数对账修正数、定时任务失败数、任务失败队列年龄和补偿结案率。
- 法规复核逾期条目数、纠错反馈 SLA、论坛举报待处理年龄。
- 关键埋点入库量与客户端触发量抽样比对；事件属性不得包含 token、openid、手机号、正文。

## 关闭与回滚

1. 先关闭高风险写开关：`forum.write_enabled=false`，必要时 `forum.enabled=false`。
2. 再关闭路线/法规入口开关；V1 约骑、活动、消息和个人中心保持可用。
3. 回滚应用代码或前滚兼容修复；不自动删除新增数据和审计证据。
4. 迁移异常时停止生产迁移，使用备份恢复并保留演练日志；禁止修改历史迁移。
5. 值班人记录 request ID、影响范围、告警时间线和恢复验证结果。
