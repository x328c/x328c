# S5 监控指标与埋点字典

## 服务端指标

- `api.requests`：按规范化路由、HTTP 状态统计请求数、错误数和 p95 延迟。
- `counter.reconciliation.runs` / `counter.reconciliation.mismatches`：计数对账运行与修复量。
- `task.failure`：任务失败、重试、人工补偿；失败摘要不包含正文、token、openid、手机号或精确位置。
- `forum.moderation.timeout` / `forum.moderation.pending`：审核超时与积压。
- `regulation.review.overdue`：法规复核逾期。
- `report.sla.overdue`：举报 SLA 逾期。
- `db.query.slow`：慢查询采样（仅 SQL 模板/耗时，不记录参数值）。

## 客户端事件

允许事件：`route_list_view`、`route_detail_view`、`route_favorite_toggle`、`route_related_rides_click`、`regulation_search`、`regulation_detail_view`、`regulation_feedback_submit`、`forum_board_view`、`forum_post_view`、`forum_post_submit`、`forum_reply_submit`、`forum_like_toggle`、`forum_report_submit`、`feature_blocked`、`state_panel_view`。

属性只允许小写下划线键和 string/number/boolean 值，最多 20 项；禁止正文、图片 URL、token、openid、手机号和精确位置。客户端同时调用 Taro 本地埋点和 `POST /api/v1/telemetry/events`，服务端以 `event_id` 唯一约束保证幂等。

## 验证状态

服务端入库单测已验证首次写入与重复 `event_id` 幂等，API 错误/延迟指标由 LoggerMiddleware 端到端记录。真实生产指标导出器、告警通道和真机上报仍是 S6 外部依赖，不能用客户端函数调用代替验收。
