# S5 运营与应急 SOP

## 审核积压/异常

监控发现审核超时或积压后，保持内容 `PENDING`，暂停 `forum.write_enabled`，在后台“论坛治理”处理异常队列。管理员可重试、人工通过或驳回；每次操作必须填写原因并检查审计记录。不得通过修改数据库状态绕过审核。

功能开关统一在后台“功能开关”页面操作。修改仅限超级管理员，必须填写原因并二次确认；完成后核对页面回读值和 `operation_logs` 中的 `feature_flags.update`。禁止以直接修改数据库代替正常运营操作。

## 计数异常

后台“集成运维”查看对账指标。先确认事实表和时间范围，再填写说明执行计数对账；修正数量异常时创建 P1 事件并保留操作日志。重复执行必须可安全收敛。

## 法规来源/复核逾期

来源链接失效或复核逾期时，将条目标记待复核并从推荐位移除；保留来源 URL、历史修订和纠错反馈，不生成法律结论、不原地覆盖已发布正文。

## 举报 SLA

每日检查论坛举报队列年龄；24 小时内完成初判，涉及安全/违法风险立即升级负责人。下架、禁言和忽略均填写处置原因并核对 `operation_logs`。

## V1 保护

任何 V2 开关或任务故障演练后必须执行 V1 登录→约骑→报名→通知冒烟；V1 指标下降超过 2 个百分点时停止扩大灰度并按回滚手册处理。
