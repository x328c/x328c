## 构建限制

Taro 4.2 的 macOS 原生 doctor 配置校验可能报 `system-configuration` NULL object。仓库构建脚本使用 CLI `--no-check`，并执行独立 app.config、Tab、路由和图标校验；CI 仍应在稳定 runner 单独运行 doctor。4/5 Tab 产物本轮均已成功生成。
