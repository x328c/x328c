以下项目无法由仓库代码单独证明，不应被描述为已完成的生产验收：

1. 运营提供并安全复核 30 条真实路线；路线类型枚举需产品最终确认；

3. 微信开发者工具和至少一台真机验证地图加载失败降级、分享和登录回跳；
4. 在部署环境以真实数据分布和并发测量 API P95；
5. 灰度前由授权人员显式开启 `route.enabled`，并执行关闭/回滚演练；
6. 管理后台仍有 3 个既有页面 hooks warning，Vite 仍有大 chunk 警告；应在 S5 处理，不属于 S2 新增失败。

在以上外部门禁完成前，`route.enabled` 必须保持默认关闭。
