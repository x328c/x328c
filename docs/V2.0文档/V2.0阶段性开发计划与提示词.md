## 1. 使用方法

本文件包含一份总控提示词和七个阶段提示词。推荐使用方式：

1. 新开发任务先发送“总控提示词”；
2. 再发送当前阶段提示词，只授权一个阶段；
3. 编码助手完成阶段内一个可独立验收的纵向切片后运行检查；
4. 依据阶段门禁决定继续、修复或裁剪，不跳过失败项；
5. 每次交付更新任务状态、测试证据和剩余风险。

不要一次要求模型实现全部 V2.0。单次开发任务建议控制在 0.5-2 个工作日、一个明确模块或一条端到端流程内。

## 2. 固定开发约束

这些约束适用于所有阶段：

- 工作目录：`/Users/xuchangxin/projects/jiangxing`；
- 后端：`backend/`，NestJS 10 + Prisma 5 + MySQL 8 + Redis 7；
- 小程序：`frontend/`，Taro 4.2 + React 18 + Zustand；
- 管理后台：`admin/`，React 19 + Vite 8 + Ant Design 6；
- API 兼容新增继续使用 `/api/v1`，产品 V2.0 不等于 API `/api/v2`；
- Prisma Schema 是数据模型事实源，不直接执行技术文档中的示意 SQL；
- 不修改或合并已经执行过的 V1.0 历史迁移，只新增增量迁移；
- 不把审核服务异常当作放行条件；UGC 保持待审核；
- 不记录 token、openid、手机号、精确位置、法规/帖子全文等敏感日志；
- 不实现 PRD“明确不做”的 V2.1 能力；
- 不擅自删除、覆盖或回滚用户已有的未提交改动；
- 不修改 `.env`、生产密钥或真实第三方配置；
- 不自动提交、推送或部署，除非用户明确授权；
- 新增功能必须有权限、异常状态、测试、日志/审计和关闭开关；
- 优先沿用现有模块风格，不为了“架构统一”进行无关大重构。

### 8.2 阶段提示词

```text
执行 S2 路线精选 MVP。只做官方/运营路线，不实现用户路线 UGC、GPX/KML、评分或完整轨迹附近搜索。

数据模型：
- 按技术方案实现 Route、RoutePoint、RouteFavorite、RouteRideLink 及 Prisma 关系。
- 路线状态为草稿、已发布、已下架；收藏使用 userId+routeId 唯一约束。

API：
- GET /api/v1/routes：城市、类型、难度筛选，稳定游标分页，只返回已发布内容。
- GET /api/v1/routes/:id：公开详情；下架内容按权限返回明确状态。
- PUT/DELETE /api/v1/routes/:id/favorite：幂等且计数一致。
- GET /api/v1/routes/:id/related-rides：只返回当前可见、未删除的有效约骑。
- 管理端完成草稿、编辑、预览、发布、下架；发布字段完整校验；发布/下架写审计日志。

小程序：
- 新增路线分包、列表和详情，复用统一状态组件。
- “附近”使用“本城路线”文案，不宣称按整条轨迹测距。

测试与验收：
- 覆盖未发布泄露、越权发布、重复收藏、下架缓存、无效游标、软删除、关联约骑可见性。

- route.enabled=false 时接口和页面安全关闭，不影响 V1 约骑。
- 运行三端对应构建与测试，报告查询索引和性能基线。
```

## 9. S3 — 法规检索 MVP

### 9.1 任务顺序

| ID | 任务 | 核心验收 |
|---|---|---|
| S3-01 | 法规与修订模型 | 来源、地区、版本、状态、双人复核可追溯 |

| S3-04 | CSV 导入与后台 | 校验、预览、错误行、只导入草稿 |
| S3-05 | 小程序法规页 | 搜索、来源块、失效/过期提醒、纠错 |
| S3-06 | 搜索验收 | 真实词集 Top3 命中率 ≥90% |

### 9.2 阶段提示词

```text
执行 S3 法规检索 MVP。产品提供结构化官方信息索引，不实现 AI 问答、自动采集或法律结论。

数据与工作流：
- 实现 Regulation、RegulationRevision、RegulationTag、适用地区关系和 RegulationFeedback。
- 全国范围使用显式 scope；不能用空数组暗示全国。
- 每次发布形成可追溯修订；已发布正文不原地覆盖。
- 录入人与复核人不能相同；发布、失效和下架均写审计日志。
- 已发布条目必须有标题、文号/可空理由、发布机构、效力层级、适用地区、状态、来源 URL、生效信息、最后复核时间和当前修订。

检索：
- 首期数百条数据使用可验证的规范化字段、标签和数据库查询，不先引入 Elasticsearch。
- 搜索标题、文号、发布机构和标签；默认只显示现行有效。
- 以真实中文关键词集验证排序；不要仅用英文/ID 测试。
- 无结果返回空结果和建议，不调用生成式模型补答案。

CSV 导入：
- 上传→结构/字段/重复校验→预览→确认→导入草稿。
- 错误行可定位；导入必须幂等或可识别重复任务。
- CSV 不允许直接发布；文件大小和行数有限制。

小程序与后台：
- 小程序实现分类/城市/关键词检索、详情 SourceBlock、失效/已替代/逾期复核提示和纠错反馈。
- 后台实现草稿、复核、修订、发布、失效、下架和导入任务。
- 官方原文使用明确外链文案；链接失败不隐藏来源字段。

测试与验收：
- 覆盖同人复核、缺来源发布、历史修订、失效默认过滤、链接失效反馈、重复导入、越权发布。
- 用至少 30 个真实关键词完成 Top3 命中率报告，目标 ≥90%。
- regulation.enabled=false 时安全关闭且不影响路线/约骑。
- 完成“导入草稿→另一管理员复核→发布→小程序搜索→查看来源→提交纠错→修订”的纵向冒烟。
```
