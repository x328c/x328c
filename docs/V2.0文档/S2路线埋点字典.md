# S2 路线精选埋点字典

> 状态：代码已接入，微信分析后台事件配置和测试账号入库验证待灰度前完成。  
> 隐私边界：只发送路线/约骑业务 ID、城市码、枚举筛选和结果计数；不发送 token、openid、手机号、精确坐标、请求正文或路线全文。

| 事件 | 触发时机 | 属性 | 去重/解释 |
|---|---|---|---|
| `route_module_exposure` | 路线 Tab 每次进入前台 | 无 | 每次 `useDidShow` 记一次，用于模块曝光会话计数 |
| `route_list_result` | 列表请求成功 | `city_code`、`type`、`difficulty`、`result_count`、`has_more`、`append` | 每次成功请求一次；`append=true` 表示加载下一页 |
| `route_filter` | 用户确认城市或选择类型/难度 | `city_code`、`type`、`difficulty` | 每次用户动作一次；未选择值统一为 `all` |
| `route_detail_view` | 详情接口成功且正文可展示 | `route_id` | 每次成功进入详情一次；错误、下架和关闭页不计详情查看 |
| `route_favorite` | 收藏或取消收藏接口成功 | `route_id`、`favorited` | 只在服务端成功后发送；幂等重复请求仍按用户动作记录 |
| `route_related_rides_click` | 点击相关约骑卡片或底部主按钮并准备跳转 | `route_id`、`ride_id` | 每次有效点击一次；无相关约骑时不发送 |

数据负责人由产品/运营在灰度清单中指定。上线前必须使用测试账号检查微信分析后台实际入库、字段类型和事件名称，不能只以客户端调用成功作为通过证据。
