# V2.2 开发实现与验证报告

日期：2026-08-16

## 1. 本轮实现范围

### 后端

- 下线活动、论坛运行时代码及模块注册，保留历史数据库表作为归档数据。
- 为旧活动、论坛接口增加一个版本周期的 HTTP 410 兼容响应，业务码为 `57001`。
- 将文件访问、埋点、举报、计数对账、安全协议等逻辑与活动、论坛解耦。
- 新增法规单条、批量永久删除接口，仅角色 9 可用；删除原因、目标摘要及数量写入操作日志，法规正文不写入日志。
- 新增 V2.2 法规数据清理脚本：默认仅生成候选清单和汇总报告；正式执行必须同时提供执行参数和候选数量确认值，并在事务中完成清理和校验。
- 新增“安全骑行倡议”公开读取接口，正文采用 `safe_riding_initiative/v1` 稳定结构。
- 后台倡议编辑改为输入 Markdown 纯文本，由后端自动解析摘要、10 个章节和 HTTPS 来源，不再要求运营人员手写 JSON。
- 将《安全骑行倡议内容稿》导入本机开发库并发布为 `2026.08.1`，内容哈希为 `sha256:da06f3b2cd04093d8d8d22af33a1cb2c519f8cb1b3d37cfd58c54ef076253c11`。

### 小程序

- 固定为“同行助手、路线、助手通知、我的”四个 Tab。
- 删除活动、论坛页面、分包、服务、状态和入口；历史通知仅保留展示能力，不再跳转至已下线功能。
- 法规手册简化为关键词检索，默认只展示已发布的摩托车法规。
- 新增安全骑行倡议卡片和详情页，倡议加载状态与法规列表相互独立。
- 开启 `lazyCodeLoading: requiredComponents`，并在构建脚本中校验四 Tab、退役路径、代码压缩和分包体积。

### 管理后台

- 删除活动管理、论坛审核和对应统计入口。
- 内容管理聚焦同行内容；安全内容支持事故指南和安全骑行倡议的新增、编辑与发布。
- 法规列表新增角色 9 专属的单条、批量永久删除能力，必须填写删除原因并二次确认。
