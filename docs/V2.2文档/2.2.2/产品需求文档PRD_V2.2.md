# 摩搭子助手 V2.2 产品需求文档

## 1. 目标与范围

V2.2 聚焦摩托车骑行同行、路线发现和安全知识。删除“活动”与“论坛”两套与同行助手重叠或超出个人开发者定位的能力，降低内容治理、审核和运维成本。

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| CORE-01 | 删除活动功能 | 小程序、后台、API 与任务中不再提供活动创建、报名、管理或通知入口；历史表只读归档 |
| CORE-02 | 删除论坛功能 | 小程序、后台、API 与任务中不再提供论坛发帖、回复、点赞、审核或举报入口；历史表只读归档 |
| MINE-01 | 精简“我的” | 删除“发布同行”“参加活动”“我的活动”入口；保留“我的同行”、资料、设置与路线入口 |
| REG-01 | 手册内容收敛 | title、tags、summary、content 四个字段均不含“摩托车”的法规，含其修订、标签、区域、反馈等关联数据一并永久删除 |
| REG-02 | 简化手册筛选 | 删除手册页全部筛选控件和城市码输入；保留关键词检索、法规列表、详情、来源和纠错反馈 |
| REG-03 | 后台删除 | 管理员可单条删除或勾选批量删除法规，必须二次确认、填写原因并记录审计日志 |
| SAFE-01 | 安全骑行倡议 | 在手册顶部展示一个倡议入口；后台可编辑标题、摘要、正文、版本与发布状态 |
| PKG-01 | 包体优化 | 开启 JS 压缩和 `lazyCodeLoading: requiredComponents`，并完成首页、路线、设置及安全手册回归 |

## 2. 用户流程

1. 用户打开“骑行安全手册”，先看到安全骑行倡议卡片，可进入阅读全文。
2. 用户可直接输入关键词搜索摩托车相关法规；页面不再显示城市码、类别、难度或其他筛选按钮。
3. 管理员在“法规管理”中勾选一条或多条法规，填写删除原因后执行删除；删除后不再出现在前台及后台列表。
4. 管理员在“安全内容”中创建、编辑、发布或下线安全骑行倡议；前台只读取当前已发布版本。

## 3. 不做事项

- 不将安全倡议作为法规原文、执法依据或法律咨询意见。
- 不保留活动/论坛历史记录的公开查询或兼容 API；历史数据只读归档，物理清表另立审批和保留期方案。
- 不新增社交、社区、资讯或新闻类功能。

## 4. 发布验收

- 所有 `/activities`、`/forum` 及相应 `/admin` 路由均不存在；前端无可达页面和菜单。
- 删除规则在迁移演练数据库上可重复执行，且删除前生成可审计的数量报告。
- 倡议无已发布内容时显示“倡议内容正在完善”，不影响法规检索。
- 代码质量检测的“JS 文件压缩”“组件按需注入”均通过，真实设备关键页面可正常打开。

## 5. 详细业务规则

### 5.1 活动与论坛下线

- 所有用户入口、分享路径、深链、消息跳转和空状态文案同时移除，禁止出现点击后 404 的残留入口。
- 旧版本客户端访问已下线路由时，网关返回统一业务码和“请升级到最新版本”提示；V2.2 小程序本身不再携带旧页面代码。
- 历史活动、报名、论坛内容、审核和举报数据不再新增或修改，仅供依法处理存量投诉、争议和审计。
- 通知列表遇到历史 `activity`/`forum` 类型时显示普通历史通知，不再提供详情跳转。

### 5.2 法规保留判定

对每条法规使用以下四组文本判定：法规标题、全部标签、当前发布修订摘要、当前发布修订正文。四组文本均不包含连续字样“摩托车”时，列入永久删除集合；任一组包含则保留。没有当前发布修订的草稿，使用最新修订摘要和正文判定。

判定区分大小写不适用于中文，但必须处理 `NULL`、空标签和空正文；空值按“不包含”处理。仅含“机动车”“两轮车”“电动车”而不含“摩托车”的记录仍删除，这是本次产品规则，不做同义词扩展。

### 5.3 安全倡议状态

- 草稿：仅后台可见，可反复编辑。
- 已复核：由非创建人完成内容复核，等待发布。
- 已发布：前台唯一可见版本；新版本发布时旧版本自动归档。
- 已下线：前台不展示，后台保留修订和审计记录。
