# 摩搭子助手 V2.2 UI/UX 设计思路

## 小程序

- 首页只保留“同行助手”列表；移除“活动”页签和所有活动跳转。
- “我的”只显示与个人骑行直接相关的入口：资料编辑、我的同行、我的路线、设置。按原始需求删除“发布同行”“参加活动”“我的活动”；首页悬浮按钮仍是唯一“发起同行”入口。
- 骑行安全手册顶部采用橙色描边的“安全骑行倡议”信息卡，显示标题、两行摘要与“阅读全文”。正文页使用清晰分节、来源提示和更新时间，不使用夸大或强制同意语。
- 手册主页面保留搜索与法规卡片；移除城市码搜索框、分类、难度及其他筛选按钮，空状态提示“暂无摩托车相关法规”。

## 管理后台

- 法规管理表格增加多选、单条“删除”和批量“删除所选”。危险操作使用红色按钮、二次确认，确认框要求填写删除原因并显示影响条数。
- 安全内容菜单下新增“安全骑行倡议”，表单包含标题、摘要、正文、版本和发布状态；列表显示当前版本、状态、更新时间、操作者。
- 移除论坛审核、论坛举报、活动管理页面与侧边栏入口。

## 页面结构

### 骑行安全手册

1. 顶部标题与说明；
2. 安全骑行倡议卡片；
3. 骑行应急知识卡片；
4. 单一关键词搜索框；
5. 法规结果列表与加载状态。

搜索框占满卡片宽度，确认键触发搜索；不提供城市码、类别、状态筛选。结果默认只显示现行有效法规。空状态文案为“暂无匹配的摩托车相关法规”，并提供“清空关键词”。

### 安全骑行倡议详情

顶部显示标题、版本和最近复核日期，正文按“出发前、骑行中、结伴骑行、恶劣天气与夜间、故障和事故、文明责任”分节。底部展示来源列表和“内容为一般安全提示，请以现行法律法规及现场管理要求为准”。页面不设置勾选、强制阅读或同意按钮。

## 交互与无障碍

- 删除按钮不得只用图标表达；必须同时显示“删除”文字。
- 危险确认弹窗默认焦点不落在确认按钮，取消按钮始终可见。
- 倡议和法规正文支持系统字体缩放；重要提示不只依赖颜色区分。
- 加载失败只影响当前内容卡片，不得使整个手册白屏。
