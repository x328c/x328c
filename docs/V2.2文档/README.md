## 版本边界

1. 删除用户侧、管理端和后端的“活动”与“论坛”业务入口、接口与定时任务；不再提供历史内容访问。历史表先只读归档，不在本次迁移中物理删除。
2. 同行助手继续作为唯一的线下骑行撮合业务；路线、评论、举报、安全确认保留。
3. 骑行安全手册仅展示摩托车相关法规；不相关法规从数据库永久删除。
4. 安全骑行倡议是可后台管理、公开展示的运营内容，不冒充法律法规或专业法律意见。
5. V2.2 仍使用 `/api/v1`；本次删除为有意的破坏性升级，发布前必须完成客户端版本门禁及备份。
