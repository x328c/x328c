# V2.2 数据清理与功能下线清单

## 1. 授权边界

本次唯一明确授权永久删除的数据是“不含‘摩托车’的法规”。活动和论坛仅下线功能、接口和管理页面，历史数据先只读归档。任何生产库 `DROP TABLE`、论坛媒体对象删除或活动报名数据清除均需另行确认。

## 2. 法规删除判定

一条法规满足以下四项全部为真时删除：

1. `regulations.title` 不含“摩托车”；
2. 关联标签名称拼接后不含“摩托车”；
3. 当前修订摘要不含“摩托车”；无当前修订时取最高版本修订；
4. 同一修订正文不含“摩托车”。

删除前必须生成两份报告：候选明细（ID、标题、文号、状态、修订 ID）和按状态汇总数量。报告经人工抽检后才允许执行。

## 3. 法规迁移顺序

1. 创建临时候选 ID 集合并锁定本次判定结果；
2. 导出候选清单和总数；
3. 将候选法规关联的 `regulation_import_rows.regulation_id` 置空；
4. 删除候选法规的 `regulation_feedbacks`；
5. 删除 `regulations`，由外键级联删除修订、标签链接、地区；
6. 删除无任何链接的孤立 `regulation_tags`；
7. 校验剩余法规每条至少在标题、标签、摘要、正文之一包含“摩托车”；
8. 记录删除数量和迁移完成时间。

生产执行前必须完成数据库完整备份；失败时整段事务回滚。上线后如发现误删，仅能从备份按 ID 恢复，不能依赖 down migration 重造正文。

## 4. 活动下线清单

- 小程序：移除活动 Tab、列表、详情、创建、我的活动及路线详情“发起活动”。
- 后端：不再注册 `ActivityModule`；移除活动控制器、服务、DTO、缓存和通知写入。
- 管理后台：移除活动列表、下架、删除入口与 API 封装。
- 安全协议：停止 `activity_create`、`activity_register` 新版本发布和前端请求；历史确认记录保留。
- 数据：`activities`、`activity_registrations`、`route_activity_links` 和相关报告/通知只读归档，不清表。

## 5. 论坛下线清单

- 小程序：移除论坛 Tab、分包、发帖、详情、我的帖子/回复入口及资源。
- 后端：不再注册 `ForumModule`；移除论坛控制器、审核调度器、守卫、限流和功能开关依赖。
- 交叉依赖：移除 `TelemetryModule`、`FileModule` 对论坛模块的导入，文件上传目录不再接受 forum 用途。
- 管理后台：移除论坛审核、举报、版块、限制和审计页面与导航。
- 数据：论坛表、`users.forum_invited`、论坛媒体文件和限制记录先保留归档；物理清理另立任务。

- [ ] 旧活动/论坛 URL 返回统一下线提示，无 500；

- [ ] 管理后台无活动/论坛菜单；
- [ ] 数据库无新增活动/论坛写入；
- [ ] 日志中没有活动/论坛定时任务继续运行；
- [ ] 剩余法规关键词一致性 SQL 返回 0 条异常记录。
