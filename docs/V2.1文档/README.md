# 摩搭子助手 V2.1 文档总览

> 文档基线：2026-08-08
> 适用范围：V2.0 基本完成后的联动、内容安全与设置完善
> 状态：技术实现及初始事故指南已上线；其他内容、运营及法务门禁按项目计划执行

## 1. 版本定位

V2.1 不重做 V2.0 架构，而是在保留 V1/V2 主链路和 `/api/v1` 兼容契约的前提下，完成四类增量改进：

1. 打通路线与同行助手（原“约骑”）、活动的创建和浏览转化；
2. 为官方路线增加受控、可治理的文字评论；
3. 完成小程序用户侧名称和入口优化；
4. 增加骑行应急知识、逐次安全确认和可实际使用的设置能力。

“同行助手”“骑行安全手册”“安全知识”是用户界面名称。后端 `Ride`、`Regulation`、既有数据库表名和 `/api/v1/rides`、`/api/v1/regulations` 不做破坏性重命名；官方文件标题、文号、效力层级和原文中的“法律/法规”用语必须保持准确。

## 4. 一致性和边界

- Prisma Schema 继续作为数据模型事实源；仅新增 V2.1 增量迁移，不修改 V1/V2 历史迁移。
- 产品版本 V2.1 不等于 API `/api/v2`；兼容新增继续使用 `/api/v1`。
- 路线评论属于公开 UGC，采用提交即发布和举报后审；达到举报阈值或命中基础检测后进入待审核，已屏蔽内容不得公开返回。
- 路线绑定不能把可变路线详情复制成唯一事实源；业务单据仍保留必要地点快照，避免路线下架或更新破坏已发起活动。
- 安全确认用于风险告知和证据留存，不得声称免除平台、组织者或参与者依法应承担的责任。
- 骑行安全手册只做一般流程提示，不判断事故责任、赔偿金额或个案处理结果。
- 设置项必须真实可用；尚无后端能力的项目不得用可切换但不生效的假开关替代。
