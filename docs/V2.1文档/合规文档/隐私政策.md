# 摩搭子助手隐私政策

版本号：2026.08.10
发布日期：2026年8月10日
生效日期：2026年8月10日

本政策说明“摩搭子助手”如何处理个人信息。运营者为微信后台公示的个人开发者【上线前填写真实姓名】，可通过“我的—设置—意见反馈”或【上线前填写有效邮箱】联系。

## 第一条 引言与适用范围

1. 本政策适用于登录、资料、路线、同行、活动、评论、设置与反馈。微信会依其规则独立处理部分信息。
2. 我们只处理实现明确功能所需的信息。拒绝非必要授权不影响其他无关功能。
3. 本服务主要面向成年人，不向未满十八周岁用户提供摩托车同行和活动服务。发现误收集不满十四周岁用户信息时，将依法删除或取得监护人同意。

## 第二条 信息收集与使用

1. **登录和账号。** 经授权，我们用微信临时凭证换取OpenID，符合条件时取得UnionID；昵称、头像用于创建账号和展示资料。登录时记录协议版本、摘要和确认时间。
2. **个人资料。** 你可选填车型、骑龄、风格、简介、城市和微信号，用于完善资料和匹配同行。联系方式是否展示由你控制。
3. **位置信息。** 仅在你使用附近功能、地图选点或录入路线时申请权限。附近功能取得的设备坐标会先随机偏移约300至800米，再保存和计算距离，不持久化该次精确定位，也不展示精确实时位置。你主动选择并保存的集合地点或路线起点、终点、途经点属于你创建的业务内容，为实现地图展示会保存地点名称和所选坐标；私密路线仅本人可见，公开路线的这些点位会向其他用户展示。请勿选择家庭住址、单位等敏感地点。
4. **图片和内容。** 你主动上传时，我们仅处理本次选中的照片及文件记录，不读取整个相册。发布内容、评论、反馈和举报材料用于展示、审核和申诉处理。
5. **报名和联系信息。** 你可选填姓名、手机号、紧急联系人和备注，仅用于活动联系、安全应急和报名管理，不用于营销。填写他人信息前应取得同意。
6. **日志和设置。** 我们处理请求时间、编号、接口结果、错误及必要设备环境，并保存可见范围、通知偏好和操作状态。日志不记录令牌、OpenID、手机号、评论全文和精确位置。
7. 相机、相册、位置和通知仅在对应功能中申请，可随时关闭。当前未接入微信手机号快捷获取；未来接入前会更新指引并单独授权。

## 第三条 信息存储与保护

1. 信息存储在中国境内，不向境外提供。未来如需出境，将依法履行评估、告知和单独同意义务。
2. 账号信息在账号存续期间保存；业务信息按提供服务、投诉处理和法定义务所需最短期限保存；安全日志一般不超过六个月。到期后删除或匿名化。
3. 上传图片在内容删除、账号注销且留存期届满后删除，备份在合理轮换周期内清除。
4. 我们采取访问控制、传输加密、日志脱敏、权限校验、限流、备份和审计等措施；发生安全事件时依法补救并告知。

## 第四条 信息共享、委托与披露

1. 我们不出售个人信息。仅在必要范围向相关用户展示你选择公开的昵称、头像、联系方式、报名状态和集合信息。
2. 服务可能使用微信登录、地图、订阅消息、对象存储和内容安全能力，提供方仅在实现相应功能所需范围处理信息。上线前须在后台列明实际第三方。
3. 运营主体变更需转移信息时会告知接收方并要求继续履行本政策；目的变化时重新取得同意。
4. 履行法定义务、保护紧急人身安全或配合有权机关时，可能在必要范围披露并保留记录。

## 第五条 你的权利

1. 你可在“我的”和“设置”访问、更正资料，调整公开范围；也可通过反馈申请查阅、复制、更正或删除信息。
2. 你可撤回位置、相机、相册和通知权限；撤回不影响此前合法处理。
3. 你可删除内容或注销账号。我们核验身份后在十五个工作日内处理或说明理由，随后依法删除或匿名化信息。
4. 附近排序主要依据城市、模糊位置、时间和业务条件，不依据敏感特征进行差别待遇。
5. 为保护账号和他人权益，我们可能要求必要的身份核验材料。

## 第六条 未成年人信息保护

1. 未满十八周岁用户不得使用摩托车同行和活动功能。监护人应避免未成年人提交姓名、联系方式、位置或图片。
2. 处理不满十四周岁用户信息需监护人同意。监护人可联系我们申请删除。

## 第七条 政策更新

1. 因法律、微信规则或功能变化更新时，我们会标注版本和日期。
2. 信息类型、目的、共享对象或用户权利发生重大变化时，将显著告知并依法重新取得同意。

## 第八条 联系方式

1. 运营者：【上线前填写微信小程序后台登记的个人开发者真实姓名】。
2. 应用内渠道：“摩搭子助手—我的—设置—意见反馈”。
3. 个人信息保护联系邮箱：【上线前填写有效邮箱】。
4. 我们通常在十五个工作日内答复；你也可依法向监管部门投诉。
