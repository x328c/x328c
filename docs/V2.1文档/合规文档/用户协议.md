# 摩搭子助手用户协议

版本号：2026.08.15
发布日期：2026年8月15日
生效日期：2026年8月15日

特别提示：摩托车骑行具有较高风险。“摩搭子助手”仅提供路线、同行或活动信息及安全知识等网络工具，不组织或指挥线下骑行，也不是运输、救援、保险或法律咨询机构。请重点阅读骑行风险和责任边界条款。

## 第一条 总则

1. 本协议是你与“摩搭子助手”运营者（下称“我们”）之间关于使用本小程序的约定。运营者为微信后台公示的个人开发者【上线前填写真实姓名】，可通过“我的—设置—意见反馈”联系我们。
2. 你点击勾选并登录，表示你已经阅读、理解并同意本协议及《隐私政策》，并已阅知《安全须知》。如你不同意，请不要注册或使用需要登录的功能。浏览公开安全知识不以同意非必要个人信息处理为前提。
3. 本服务主要面向年满十八周岁的用户。驾驶人应取得相应驾驶资格，并确保车辆依法登记、检验和投保。未满十八周岁用户不得发起、报名或参加摩托车同行和活动。
4. 因法律或功能变化需要更新协议时，我们会标注新版本；重大变化将显著告知并依法重新取得同意。不同意的用户可以停止使用并注销账号。

## 第二条 账号注册与使用

1. 你可通过微信授权登录。你应提供本人真实、合法、有效且不侵害他人权益的昵称、头像和其他资料，不得冒用组织、媒体、国家机关或他人身份，不得使用违法和不良信息作为账号资料。
2. 账号仅限本人使用。请妥善保管微信账号和设备；发现盗用或泄露时及时修改微信安全设置并联系我们。因自行泄露、转借设备等造成的损失，由责任方依法承担。
3. 你可在设置中调整资料和联系方式可见范围。不要公开身份证号、住址、银行卡或精确实时位置等敏感信息。
4. 你可在设置中申请注销。我们核验身份并处理未结束事项后停止账号服务，依法删除或匿名化信息；法定留存记录到期后处理。

## 第三条 用户行为规范

1. 不得发布违法违规、危害国家安全、破坏社会秩序或侵害他人权益的信息，包括色情、赌博、暴力、侮辱诽谤、诈骗引流及侵犯隐私等内容。
2. 禁止发布虚假同行或活动、伪造路线和集合信息、诱导危险驾驶、组织竞速飙车、酒后驾驶、无证驾驶、非法改装、超员载人，或以收费培训、旅游、营运、保险、医疗、法律咨询等名义开展超出本小程序定位和个人开发者资质范围的服务。
3. 发布者应保证时间、地点、人数、费用和风险提示真实清楚；情况变化时及时更新或取消。评论应基于真实体验、文明表达，不得刷量或引流。
4. 我们可依法采取提示改正、限制发布、删除内容、暂停功能、封禁账号或向主管机关报告等措施。用户可通过意见反馈申诉。

## 第四条 服务内容

1. 路线和安全知识仅供一般参考。道路、天气和管制可能变化，出发前应通过官方渠道复核。
2. 同行和活动只帮助用户发布和匹配信息。用户自行联系并协商路线、费用和安排；我们不因此成为线下组织者、承运人或代理人。
3. 各方应自行核验驾驶资格、车辆、保险、装备、天气和身体状态。任何人不得强迫他人违法或危险驾驶。
4. 法规和事故处理内容不构成专业意见。发生事故或人身危险时，应优先联系110、120并听从专业人员指挥。

## 第五条 平台责任限制

1. **“摩搭子助手”是骑行活动信息发布和报名撮合平台，只提供线上信息工具，不组织、不指导、不指挥，也不参与任何线下骑行活动。发起人和参与人均为独立、自愿的骑行活动参与者。**
2. 平台会按照法律规定和产品规则进行必要的信息管理，但不对发起人或参与人的驾驶资格、驾驶能力、车辆状况、保险情况、身体状况和心理状态进行实质性审查。用户应在出发前自行核实，并拒绝无证驾驶、危险驾驶或其他违法安排。
3. 平台展示的路线、天气、集合地点和用户发布内容仅供参考，不能代替用户自己的现场判断。平台不对任何骑行活动的安全性、适宜性、可行性作出明示或暗示的保证。
4. 摩托车骑行可能因交通事故、道路状况、天气变化、车辆故障或个人操作造成伤亡和财产损失。用户自愿发起或参与骑行活动，表示其已了解并愿意自行承担相应风险和责任；平台不对骑行活动中发生的人身伤害、财产损失或由此产生的法律责任承担赔偿责任。
5. 因自然灾害、恶劣天气、交通管制、通信中断等不可合理控制的原因影响服务或行程的，各方依照法律规定及各自实际过错承担责任。
6. 上述责任限制不免除平台依法应承担的信息安全、个人信息保护和必要的内容治理义务，也不排除法律规定不得排除或限制的责任。任何发起人或参与人均不得以本条免除其因故意、重大过失或违法行为依法应承担的责任。

1. 小程序程序、界面、图标和运营者制作的内容受法律保护，未经许可不得复制、抓取或商业利用，合理使用除外。

3. 不得发布无权使用的图片、文字、商标或个人信息。权利人可通过意见反馈申请处理。
