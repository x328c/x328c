# “摩搭子助手”微信小程序后台隐私保护指引填写内容

> 填写前必须把【】字段替换为微信后台登记的真实信息，并以提审版本实际调用的接口为准。下表按当前仓库代码整理，不能用“仅写入相册”替代实际发生的“选择照片并上传”。

## 一、基本信息

| 后台字段 | 建议填写内容 |
|---|---|
| 开发者/处理者名称 | 【填写微信小程序后台登记的个人开发者真实姓名】 |
| 联系方式 | 应用内“我的—设置—意见反馈”；邮箱：【填写有效邮箱】 |
| 隐私政策生效日期 | 2026年8月10日 |
| 信息存储地域 | 中华人民共和国境内 |
| 是否出境 | 否 |
| 用户权利渠道 | “我的—设置”访问和更正资料、调整权限；通过意见反馈申请查阅、复制、更正、删除、撤回同意或注销账号，通常十五个工作日内答复 |

## 二、微信后台可直接填写的信息类型

| 信息类型/权限 | 使用目的（可复制） | 使用场景与方式 | 拒绝后的影响 |
|---|---|---|---|
| 用户昵称、头像 | 用于用户授权登录后创建账号、识别用户，并在用户主动发布同行、活动或评论时展示个人资料。 | 仅在用户点击微信登录并授权资料时获取；用户可在个人资料中修改。 | 无法完成带个人资料的登录或展示；公开安全知识仍可浏览。 |
| 位置信息 | 用于用户主动选择附近内容、同行/活动集合地点，以及录入路线的起点、终点和途经点。附近功能中的个人位置在服务端先进行约300至800米模糊偏移，再用于距离计算，不向其他用户展示精确实时位置。 | 仅在用户点击地图选点或附近功能时申请。用户主动保存的集合地点或路线点位会保存名称和所选坐标；私密路线仅本人可见，发布平台的路线点位会公开展示，不用于持续追踪。 | 无法使用附近推荐或地图选点，可手动填写非精确地点或使用其他功能。 |
| 选中的照片或视频信息 | 用于用户主动上传头像、活动封面；如提审包保留图片发布功能，也用于上传用户主动选择的内容图片。 | 调用选择图片/媒体接口后，仅处理用户本次选中的文件并上传；不会读取整个相册，不会写入系统相册。 | 无法上传头像、活动封面或内容图片，可继续使用不依赖图片的功能。 |
| 摄像头（如选择图片入口允许拍摄） | 用于用户主动拍摄并上传头像、活动封面或内容图片。 | 仅在用户选择“拍摄”时由微信申请。若提审版本移除拍摄来源，应从后台删除本项。 | 无法直接拍摄，可从相册选择已有图片或跳过非必填图片。 |
| 手机号/联系信息 | 用于用户主动填写活动报名联系、紧急联系及活动组织者联络，不用于广告营销。当前版本未调用微信手机号快捷获取接口。 | 用户在需要联系的业务页面主动填写；如未来接入 `getPhoneNumber`，须先更新本指引并单独授权。 | 可能无法完成明确要求联系方式的报名；其他功能不受影响。 |

## 三、当前代码还会处理但不一定属于微信隐私接口弹窗枚举的信息

| 信息类别 | 具体内容 | 目的 |
|---|---|---|
| 账号标识 | OpenID，符合条件时的UnionID，登录时间 | 识别账号、维持会话和安全防护 |
| 自愿资料 | 车型、骑龄、骑行风格、简介、城市、微信号、资料可见范围 | 完善资料和按用户设置展示 |
| 业务内容 | 同行/活动标题、时间、地点、用户路线及可见性、费用、报名状态、评论、举报与反馈 | 提供信息工具、公开路线广场、内容审核及投诉处理 |
| 安全与设置记录 | 协议版本和确认时间、通知偏好、收藏、请求编号、错误和安全日志 | 证明授权、保存设置、防滥用和排障 |

## 四、个人开发者提审冲突与处理建议

当前仓库实际包含论坛分包、路线评论、公开个人资料、用户内容发布及线下同行撮合。仅在文案中声明“不涉及社交/社区/论坛”不能改变功能性质，也不应向微信作不实申报。个人主体版本提审前，应取得微信平台对服务类目和能力边界的书面确认；如类目不允许，应至少执行以下发布门禁：

1. 构建产物完全移除论坛页面、接口入口和可达路径，而不只是隐藏Tab；
2. 关闭路线评论写入及公开展示，并移除前端入口；
3. 评估同行/活动发布、报名、公开资料与联系方式展示是否超出个人主体允许范围；
4. 微信后台隐私信息类型、隐私弹窗、代码实际接口和本隐私政策四者逐项一致；
5. 由微信审核支持或具备资质的专业人员确认后再提交审核。
