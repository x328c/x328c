# 同行活动安全须知与风险提示协议草案

> 草案版本：2026.08.1
> 状态：法律顾问、产品和运营待评审，不得直接作为生产最终文本
> 适用动作：发起同行、加入同行、发起活动、报名活动

## 一、使用说明

本草案的目的，是让用户在发起或参加同行/活动前充分了解风险、各方角色和基本义务，并形成可审计的确认记录。它不是“无条件免责书”，不得用于免除任何主体依法不能免除的责任。

根据《中华人民共和国民法典》关于格式条款的规定，提供方应公平确定权利义务，并以合理方式提示、说明与用户有重大利害关系的条款；造成对方人身损害，或者因故意、重大过失造成对方财产损失的免责条款无效。因此，产品标题建议使用“安全须知与风险提示”，并对责任边界、风险承担、个人信息和争议处理进行显著提示。

## 二、用户展示正文

### 1. 适用与确认

欢迎使用摩搭子助手的同行助手和活动功能。请在发起或参加前完整阅读本须知。点击“我已阅读并确认”表示你已理解本次动作对应的风险提示和行为要求；该确认不影响任何主体依法享有的权利或依法应承担的责任。

每次发起、加入或报名均需单独确认当前版本。协议版本、适用动作、确认时间及对应同行/活动将由服务端记录。

### 2. 参与条件

你确认：

- 具备与驾驶车辆相符且合法有效的驾驶资格，车辆手续、保险和安全状况符合现行要求；
- 身体、精神和技能状态适合本次行程，不在饮酒、服用影响驾驶的药物、过度疲劳或其他不适合驾驶的状态下参与；
- 根据天气、道路、距离、强度和自身经验独立判断是否发起、参加、中止或退出；
- 填写的信息真实、必要且不过度披露他人隐私；
- 如法律或活动规则对年龄、监护或其他资格另有要求，应当满足相关要求。

若产品不能可靠核验未成年人监护关系，V2.1 默认不向未满 18 周岁用户开放驾驶类同行/活动的发起和报名；上线前需由产品和法律顾问最终确认。

### 3. 风险提示

摩托车骑行及线下集体出行具有固有风险，包括但不限于：交通事故、车辆故障、恶劣天气、道路施工或路况变化、落石/积水/冰雪等环境风险、路线偏离、体力或健康异常、通信中断、财物损失以及第三方行为造成的损害。

应用中的路线、点位、里程、时长、路况和安全提示可能因时间、天气、施工、交通管制或数据更新而变化，不能替代实时交通信息、现场标志、主管机关指令或用户的审慎判断。

### 4. 参与者安全义务

参与者应当：

- 遵守交通法律法规、现场交通标志和有权机关指挥；
- 正确佩戴符合要求的头盔和必要护具，不超速、不竞速、不危险驾驶；
- 与前车保持安全距离，不因跟队而闯灯、强行超车或忽视自身能力；
- 出发前检查轮胎、制动、灯光、油量/电量、紧固件及随车安全装备；
- 根据天气和身体状态及时减速、休息、中止或退出；
- 不携带违法、危险或影响安全的物品，不实施骚扰、斗殴、酒驾等行为；
- 发生危险或事故时优先保障人员安全，依法报警、求助并配合处理。

任何领队、发起人或其他参与者的路线建议、队形安排和口头提示，都不能替代你对自身驾驶行为的控制和依法驾驶义务。

### 5. 发起人和组织者义务

发起人应当如实说明时间、集合地点、路线、强度、人数、费用、车型/经验要求和已知风险，不得发布违法、虚假或明显危险的活动。

发起人不是当然的专业领队、医疗救援人员或交通管理人员，除非页面明确展示并经核验的专业资质。发起人应合理提醒安全、核对重大变更并在发现明显危险时中止或调整活动，不得强迫参与者实施危险驾驶。

活动收费、代购、拼单或费用分摊必须清晰说明。V2.1 不提供平台担保交易；参与者不要向未经核实的个人支付高额款项。

### 6. 平台角色与责任边界（重点提示）

除页面明确标注为平台官方组织的活动外，摩搭子助手主要提供信息发布、路线内容、报名连接、内容治理和必要的技术服务，不直接控制用户的车辆、驾驶行为、现场道路或第三方行为，也不当然成为用户活动的组织者、承运人、保险人或救援服务提供者。

平台将依法履行与自身服务相适应的安全保障、信息治理、隐私保护和其他法定义务。任何条款均不排除或限制平台、发起人、参与者及其他主体因故意、重大过失、人身损害或法律规定的其他情形依法应承担的责任。

因用户违反法律法规、故意隐瞒重大风险、提供虚假信息或实施侵害他人权益的行为造成损害的，由有权机关或争议解决机构依法认定相关责任，平台不通过本协议预先作个案责任判断。

### 7. 保险与救援

建议参与者根据车辆、驾驶和活动性质配置依法要求及适当的商业保险，并在出发前了解承保范围、除外责任和报案方式。平台展示保险建议不构成承保承诺。

平台不是 110、120、道路救援或保险报案渠道。遇到人员伤亡、火灾、危险品泄漏或其他紧急情况，应优先联系相应公共紧急服务并服从现场指挥。

### 8. 变更、退出与取消

天气、道路、管制、车辆或人员状况发生变化时，发起人可依法依约调整或取消，参与者也有权基于安全考虑退出。任何人不得因他人拒绝危险驾驶、选择退出或报警求助而进行侮辱、威胁或不当处罚。

费用退还、已实际发生的合理费用和第三方订单，按活动页面明确规则及相关法律处理；页面未明确时不得由本协议概括排除用户权利。

### 9. 个人信息与现场资料

平台仅为创建、报名、通知、安全和争议处理等明确目的处理必要信息，并按隐私政策说明范围和期限。手机号、紧急联系人、位置、健康或事故资料可能属于敏感信息，应按最小必要原则收集和限制访问。

用户不得擅自公开其他参与者的手机号、身份证件、精确住址、事故伤情或其他隐私。确需向公安交管、医疗、保险或司法机关提供时，应按法律规定和实际处理需要进行。

### 10. 事故与争议

发生事故时，应优先确保安全，依法报警、救助、固定证据并配合公安交管和保险处理。事故责任、损害赔偿及其他法律责任由各方协商或由有权机关、人民调解组织、仲裁机构（存在有效仲裁约定时）或人民法院依法确定。

用户可通过应用内反馈渠道提交平台服务问题。涉及人身危险、交通事故处理或紧急救援时，不应等待平台客服响应。

### 11. 内容更新

平台可因法律规则、产品能力或安全要求更新本须知。新版本仅对其生效后的新发起/报名动作要求重新确认；历史确认记录保留对应版本和内容哈希，不被新版本覆盖。

## 三、弹窗摘要（不能替代全文）

标题：**安全须知与风险提示**

摘要：

1. 摩托车出行存在交通、路况、天气、车辆和人身风险；
2. 请确认驾驶资格、车辆和身心状态适合本次行程；
3. 必须遵守交通规则，不竞速、不危险驾驶，任何跟队指令不能替代个人安全判断；
4. 除明确标注的官方活动外，平台主要提供信息与连接服务，不是现场救援或保险机构；
5. 本确认不免除任何主体依法应承担的责任；遇到危险请优先联系 110/120。

复选文案：**我已阅读完整内容，理解上述风险和行为要求，并确认继续本次操作。**

按钮：`暂不继续` / `确认并继续`

## 四、四场景差异文案

| 场景 | 弹窗补充提示 |
|---|---|
| 发起同行 | “你将成为信息发起人，请如实填写路线、时间、强度和已知风险，并及时告知参与者重大变更。” |
| 加入同行 | “请独立判断路线和强度是否适合自己，不因跟队放弃安全驾驶判断。” |
| 发起活动 | “请明确费用、报名审核、取消规则、人员要求和风险，不得把个人活动描述为平台官方活动。” |
| 报名活动 | “请核对组织者、费用、取消规则和个人信息用途，谨慎进行线下付款。” |

## 五、产品与技术落地要求

- 弹窗不得预勾选，主按钮在明确确认前不可用；
- 重大利害关系条款应以标题、加粗或其他明显标识提示，并提供说明渠道；
- 服务端按场景验证协议 ID、版本和内容哈希，前端布尔值不构成凭证；
- 业务记录和确认记录在同一事务中写入；
- 记录用户、场景、目标、协议版本、内容哈希、request ID 和时间，不记录协议全文、token、openid、手机号或精确位置；
- 新版本由不同管理员创建和复核，发布/失效写审计日志；
- 协议加载或审核状态异常时拒绝写操作，不得静默使用旧版本放行；
- 保留用户查看已确认协议版本的入口；
- 上线前完成微信小程序隐私保护指引、用户协议、隐私政策和本草案的一致性检查。

## 六、上线前法律复核清单

- [ ] 平台运营主体、客服/反馈渠道和争议解决地信息准确；
- [ ] 平台官方活动与用户自发活动的识别方式清楚；
- [ ] 未成年人参与规则与账号能力一致；
- [ ] 格式条款提示和说明方式符合要求；
- [ ] 不存在免除人身损害、故意或重大过失责任的表述；
- [ ] 收集的联系方式、紧急联系人和位置符合最小必要；
- [ ] 活动费用、退款、保险和第三方服务边界准确；
- [ ] 与用户协议、隐私政策、举报/封禁规则无冲突；
- [ ] 四个场景分别留存版本化确认记录；
- [ ] 法律顾问给出书面发布结论和下次复核日期。
